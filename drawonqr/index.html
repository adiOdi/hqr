DrawOnQR Codes

This website let's you draw on a generated QR Code. If you draw some pixels white/black (shown in green), it will optimize padding data, masking pattern, ECC level, encoding modes, and ECC distribution to find the QR code with least block damage still containing the defined content.

QR Metadata (orange) has seperate error correction. If necessary, this can also be abused to change these metadata modules.
